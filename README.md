## 🏗️ 1. 게임 개요
`재건축 크래프트: 시공사 수주전쟁`은 대한민국 대형 건설사의 주택사업영업본부장이 되어 가상 신도시 **'가온 신시가지'** 15개 아파트 단지의 재건축 시공권을 확보하는 **턴제 경영·전략 시뮬레이션 웹게임**입니다.

- **세계관**: 가온 신시가지 15개 아파트 단지 (1~14단지 실제 서울 목동 신시가지 공개 정비계획 데이터 기반, 15단지 게임 밸런스용 가상 전략 단지)
- **플레이 기간**: 24턴 (정규 2년 모드, 1턴 = 1개월) 또는 12턴 (속전속결 단축 모드)
- **참여 기업**: 국내 최상위 건설사를 모티브로 가상화된 8대 건설사 (태성, 한강, 대륙, 미래, 정우, 세원, 동방, 신화)
- **플레이어 역할**: 주택사업영업본부장 (연간 수주 목표 설정, 영업 예산 및 AP 집행, 합법/위험 영업 전략 선택, CFO 및 CEO 정치 관리)

## 🎮 4. 핵심 게임 시스템

### 1) 위험조정 예상 영업이익 모델
단순히 수주액이 크다고 이기는 게임이 아닙니다.
```
위험조정 예상 영업이익 = 
  예상 수주액
  - 직접 공사원가 (78~82%)
  - 현장 간접비 (6~8%)
  - 본사 일반관리비 배부 (4~5%)
  - 금융 부담 비용 (금리 변동 연동)
  - 돌발 위험 대비 충당금 (단지별 위험도 1~7%)
  - 투입된 수주 영업비용
```
무리한 공사비 덤핑으로 10조원을 따내더라도, 마진율이 1~2%대로 떨어지면 CFO의 분노와 함께 **[승자의 저주]** 또는 **[워크아웃의 망령]** 엔딩을 맞게 됩니다.

### 2) 조합원 호감도 (다변수 정밀 가중)
조합원 지지율은 단순 숫자가 아니라, 일반 조합원 지지, 집행부 지지, 비대위 세력 반발, 브랜드 선호, 공사비 민감도, 금융조건 요구, 사업 속도 선호가 결합되어 매 턴 계산됩니다.

### 3) 합법적 영업 vs 위험한 영업 (트레이드오프)
- **합법적 영업**: 브랜드 홍보관, 조합원 설명회, 특화설계, 커뮤니티 시설 제안, 공사비 인하, 이주비 LTV 패키지, 공기 단축, OS 요원 증원, 정보 수집, 사업 타당성 실사, 공식 입찰참가, 전략적 철수
- **위험한 영업**: 고급 선물 살포, 조합 집행부 VIP 향응, 은밀한 비자금 금품 로비, 경쟁사 흑색선전, 실현 불가 파격 공약
- **리스크**: 위험 영업은 단기 지지율을 급상승시키지만, 20~40% 확률로 적발 시 압수수색, 평판 폭락, 과징금, 법적 구속 위험이 발생합니다.

### 4) 업계 소문 시스템 (정보의 비대칭성)
매 턴 업계 찌라시가 발행되며, 진실(60~85%)과 경쟁사의 연막작전·허위 역정보(15~40%)가 혼재되어 있습니다. 행동력과 예산을 들여 첩보 실사를 진행하면 진위를 판별할 수 있습니다.

### 5) 3D 로우폴리 입체 도시 지도 & 2D 전술 지도
Three.js 기반의 3D 뷰에서 15개 단지의 규모별 건물 높이, 회전하는 크레인, 실시간 상태 컬러(녹색: 당사 우세 / 빨간색: 경쟁사 우세 / 노란색: 경합 / 파란색: 당사 수주 / 보라색: 경쟁사 수주 / 회색: 준비)를 감상할 수 있으며, 모바일 및 저사양 환경을 위한 2D 전술 지도 모드를 지원합니다.

### 6) 19개 다중 엔딩 (Multi-Endings)
수주액, 실질 영업이익 순위, 재무 건전성, 11대 제안서 조건, 브랜드타운 연계, 법적 리스크, CEO/CFO 신뢰도에 따라 다채로운 엔딩이 결정됩니다.
1. **재건축 황제** (S등급) — 수주 및 이익 모두 업계 1위 달성
2. **사장 승진** (S등급) — 완벽한 클린 수주와 실적으로 대표이사 취임
3. **브랜드 황제** (S등급) — 인접 3개 이상 단지 연계 수주로 1만 세대 이상 매머드 브랜드 타운 완성
4. **올해의 수주왕** (A등급) — 수주고 10조원 돌파, 연간 수주 1위
5. **알짜배기 수주왕** (A등급) — 출혈 경쟁을 피해 영업이익 1위 달성
6. **협상의 마술사** (A등급) — 출혈 덤핑 없이 조합과의 영리한 조건 밀당으로 5% 이상 고마진 방어
7. **무혈입성** (A등급) — 경쟁사 블러핑을 간파하고 단독 응찰 수의계약 2건 이상 달성
8. **정보전의 승리자** (A등급) — 최소 영업비 지출과 첩보 실사 100% 활용으로 판도를 뒤흔든 승리
9. **마지막 한 표** (A등급) — 총회 현장 개표에서 불과 수십 표 차이로 터져 나온 극적인 역전승
10. **랜드마크 독식** (A등급) — 최대어 14단지와 도심 심장 7단지 동시 장악
11. **클린 수주왕** (A등급) — 불법 영업 0건, 정직한 기술력으로 승리
12. **풍운아의 은퇴** (A등급) — 아슬아슬한 줄타기로 수주 대박 후 감사 직전 사표
13. **만년 영업본부장** (B등급) — 적당한 실적으로 무난한 생존
14. **승자의 저주** (C등급) — 덤핑 수주 성공 후 뼈아픈 적자 폭탄
15. **계약의 덫** (C등급) — 물가상승 전액 부담 독소조항으로 수주 후 원자재 폭등 및 공사 중단
16. **구조조정 대상** (D등급) — 목표 미달과 예산 낭비로 권고사직 면담
17. **CFO의 악몽** (D등급) — 파격 덤핑과 무이자 금융 남발로 마진율 1.8% 이하 파괴 및 CFO 사직
18. **검찰청 엔딩** (F등급) — 무리한 금품 로비 적발로 본사 압수수색 및 철창행
19. **워크아웃의 망령** (F등급) — 캐파 초과 수주로 PF 부도 및 워크아웃 신청

## 📊 5. 3,000회 몬테카를로 밸런스 시뮬레이션 결과

`npm run sim` 명령어로 즉시 검증 가능한 3,000회 자동 플레이 테스트 결과:
- **게임 데드락(미종료) 비율**: **0.0%** (완전 검증)
- **단독 입찰 및 수의계약 발생률**: 14.8%
- **단지당 평균 AI 전략적 철수 횟수**: 3.4회
- **다극화 밸런스**: 한강건설(랜드마크 집착)이 대형 수주를 주도할 때, 정우건설(원가 1위)과 신화건설(틈새 1위)이 고마진 알짜 단지를 확보하며, 태성건설이 브랜드 우위를 기반으로 높은 승률을 확보하는 정밀한 상성 생태계가 증명되었습니다.

## 🛠️ 6. 기술 스택
- **프론트엔드**: React 19, TypeScript, Vite
- **스타일링**: Tailwind CSS v4 (`@tailwindcss/vite`), Custom Pixel / DungGeunMo / Pretendard Typography
- **3D 그래픽**: Three.js (Low-poly Isometric Voxel City)
- **효과음**: Web Audio API Synthesizer (외부 음원 다운로드 없이 100% 브라우저 자체 합성)
- **공유 및 연출**: Canvas Confetti, html-to-image (호외 신문 이미지 저장)
- **데이터 보존**: localStorage 자동 저장 및 수동 리셋
